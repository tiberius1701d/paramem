Identify every value in the extracted personal facts and transcript that is an instance of one of the listed PII categories, decide a type-prefixed placeholder for each, and rewrite the transcript with those values replaced. Return BOTH a `real_value → placeholder` mapping AND the rewritten `anonymized_transcript` as a JSON array of turn strings, one element per turn — no other keys.

## Scope

Categories to scrub: {scrub_categories}

Placeholder a value ONLY if it is an instance of one of these categories. Everything else — city, organization, product, or any category not listed — stays verbatim, even if it is a proper noun or an identifying name of some kind.

Doubt can come from two different questions. They are not the same question, and they resolve in opposite directions:
- **Membership: is this category listed above at all?** A lookup, not a judgment — e.g. checking whether "city" appears in the category list. When THIS is what you're unsure about, leave the value verbatim.
- **Instance: the category IS listed — is this particular value really an instance of it?** e.g. "phone number" is listed — is `+49 151 2345` a phone number or an order reference? When THIS is what you're unsure about, placeholder the value. Over-scrubbing here costs nothing lasting — it becomes an opaque token restored locally when the reply comes back. Under-scrubbing sends real PII to the cloud, and that can never be undone.

## Placeholder shape contract

Each placeholder is `<Prefix>_<N>` where:
- `Prefix` is a PascalCase noun naming the value's category. Common prefixes are `Person`, `Phone`, `Email`, `Address`, `Profile`, but you may use any type-appropriate PascalCase prefix when one of these doesn't fit the listed categories.
- `N` is a positive integer. Allocate the smallest free index per prefix in order of first appearance (`Person_1` before `Person_2`).
- Each real value must map to a UNIQUE placeholder. No two real values share the same placeholder.

## Rules

- **`speaker{{N}}` (e.g. `speaker0`) is already anonymous — leave it VERBATIM.** It is the extractor's own anonymous handle for the person talking, not an identifying name. NEVER add a `speaker{{N}} → Person_N` entry to `mapping`, and never treat `speaker{{N}}` as a value to anonymize.
- **Totality:** once you HAVE decided a value is in scope, you MUST add its `real_value → placeholder` entry to `mapping` in the same response — every placeholder decision you make must be backed by a mapping entry, with no exceptions.
- Mapping direction is `real_value → placeholder`: the real value is the JSON KEY, the placeholder is the JSON VALUE.
- Use the SAME placeholder for every occurrence of a value across the facts, the transcript, and your `anonymized_transcript` output.
- The facts and transcript below are the material to work from. Common nouns are NEVER added to the mapping, even if the extractor capitalised them. "Dog", "Partner", "Friend", "Assistant", "User" are common nouns — they are never PII regardless of scope.
- Numeric values, dates, and currencies that do not belong to one of the listed categories stay verbatim. A phone number IS in scope when "phone number" is listed — mint a placeholder for it like any other in-scope value.
- **`anonymized_transcript` is a JSON array of turn strings, one element per turn, in the same order as the input, each a faithful rewrite of that turn changing ONLY the values you placeholdered.** Keep every `[user]`/`[assistant]` marker with its turn. Wording, punctuation, and structure everywhere else must be identical to the original. Do not summarize, paraphrase, drop, merge turns, or add content beyond the substitutions.

## Examples

POSITIVE — in-scope name substituted, out-of-scope place left verbatim (membership doubt — resolves to verbatim):
scrub categories: person name
facts: [{{"subject": "Alice", "predicate": "lives_in", "object": "Berlin", "relation_type": "factual", "confidence": 1.0}}]
Transcript: "[user] My friend Alice lives in Berlin. [assistant] Got it."
Output:
{{"mapping": {{"Alice": "Person_1"}}, "anonymized_transcript": ["[user] My friend Person_1 lives in Berlin. [assistant] Got it."]}}
Note: "Berlin" fails the MEMBERSHIP question — "city" is not a listed category at all — not the instance question. It stays verbatim.

POSITIVE — instance-ambiguous value in a listed category, placeholdered on doubt (instance doubt — resolves to placeholder):
scrub categories: physical address
facts: [{{"subject": "Rowan", "predicate": "mentioned", "object": "Lindenstraße 44", "relation_type": "factual", "confidence": 1.0}}]
Transcript: "[user] The label just said Lindenstraße 44, I couldn't tell if that was their home address or the name of the shop."
Output:
{{"mapping": {{"Lindenstraße 44": "Address_1"}}, "anonymized_transcript": ["[user] The label just said Address_1, I couldn't tell if that was their home address or the name of the shop."]}}
Note: "physical address" IS listed, and the value is address-SHAPED even though the transcript voices doubt about what it refers to — that is instance doubt, not membership doubt, so it resolves to a placeholder. ("Rowan" stays verbatim here since "person name" is not in this example's scrub list.)

NEGATIVE — incomplete mapping (a decided-on value omitted):
scrub categories: person name, phone number
facts: [{{"subject": "Honda", "predicate": "has_phone", "object": "+1 555 0100", "relation_type": "factual", "confidence": 1.0}}]
Transcript: "[user] Their sales line is +1 555 0100, and my number is +1 555 0199."
WRONG: {{"mapping": {{"+1 555 0100": "Phone_1"}}, "anonymized_transcript": ["[user] Their sales line is Phone_1, and my number is +1 555 0199."]}}
"+1 555 0199" is also an in-scope phone number — deciding to anonymize the first number but leaving the second unmapped is incomplete. Every value you decide to anonymize gets an entry, not just some of them.
RIGHT: {{"mapping": {{"+1 555 0100": "Phone_1", "+1 555 0199": "Phone_2"}}, "anonymized_transcript": ["[user] Their sales line is Phone_1, and my number is Phone_2."]}}

NEGATIVE — duplicate placeholder for two distinct values (uniqueness violation):
WRONG: {{"mapping": {{"Alice": "Person_1", "Pat": "Person_1"}}}}
Each real value must map to a unique placeholder. Allocate `Pat → Person_2`, not a duplicate of `Person_1`.

NEGATIVE — self-mapped placeholder (key is a placeholder shape):
WRONG: {{"mapping": {{"Person_1": "Person_1"}}}}
Every mapping KEY must be a real value copied verbatim from the input facts or transcript. Never use a placeholder shape (`<Prefix>_<N>`) as a KEY. A self-mapped entry is kept as-is at canonicalisation (it is not dropped), but it is a useless no-op: it never captures the real value you meant to anonymize, so that value is never actually scrubbed.

NEGATIVE — transcript rewritten beyond the substitutions:

WRONG: {{"mapping": {{"Alice": "Person_1"}}, "anonymized_transcript": ["[user] My friend Person_1 lives in Berlin."]}}
Dropping "she's great." is not a substitution — it is content loss. `anonymized_transcript` must preserve everything except the listed substitutions.
RIGHT: {{"mapping": {{"Alice": "Person_1"}}, "anonymized_transcript": ["[user] My friend Person_1 lives in Berlin, she's great."]}}
