# Sectioned prompt home for local anonymization. Every render is the SAME
# two sections below, regardless of the configured scrub categories —
# `sanitization.scrub` selects nothing in this file; the category label
# union it drives lives in the span tagger's model vocabulary, not here.
# The local model keeps exactly one anonymizer duty: deciding which tagged
# value, if any, the speaker introduced as their own name. Sections are
# composed by paramem.graph.anonymizer_prompts and parsed via the `===`
# sentinel format (paramem/graph/prompts.py::_load_prompt_sections).

=== ANCHOR-SYSTEM ===
You decide which of the given values, if any, the speaker introduced as their own name. Output valid JSON only.

=== ANCHOR ===
`{speaker_id}` is this session's own speaker anchor — the anonymous handle for the person speaking as `[user]` in the transcript below.

Below is a list of values that were flagged for anonymization. Decide which of these values, if any, the `[user]` introduces as THEIR OWN name — a self-introduction such as "I'm Priya", "my name is Priya", "call me Priya". Every spelling the `[user]` uses to introduce themselves folds onto the SAME anchor — if they say both "Priya" and "Priya Sharma" as self-introductions, list both. A value belonging to someone else — a friend, colleague, or anyone the `[user]` talks ABOUT rather than introduces as themselves — is NOT self-introduced, no matter what any other fact claims about them.

Values: {values}

Transcript:
{text}

POSITIVE — self-introduction in the transcript:
Values: ["Priya"]
Transcript: "[user] Hi, I'm Priya."
Output: {{"self_introduced": ["Priya"]}}

POSITIVE — NO self-introduction, the name belongs to someone else:
Values: ["Mira"]
Transcript: "[user] Mira, my friend, moved away for a new job."
Output: {{"self_introduced": []}}
Note: the `[user]` never says "I'm Mira" — Mira is the speaker's friend, not the speaker.

POSITIVE — two self-naming surface forms, both self-introduced:
Values: ["Priya Sharma", "Priya"]
Transcript: "[user] Hi, I'm Priya Sharma. [assistant] Nice to meet you. [user] You can just call me Priya."
Output: {{"self_introduced": ["Priya Sharma", "Priya"]}}

Return JSON only with exactly the key "self_introduced" (a JSON array of strings, a subset of the listed values). No prose, no markdown, no extra keys.
