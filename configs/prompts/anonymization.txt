# Sectioned prompt home for local anonymization. Two duties, four sections:
# SCAN names every value in the payload and marks it with one keyword from
# `configs/schema.yaml`'s `anonymizer.prefixes` table (every row, whether
# the operator scrubs it or not — `sanitization.scrub` selects nothing in
# this file); ANCHOR decides which tagged person value, if any, the speaker
# introduced as their own name. Code — never the model — decides which
# keyword's values are kept and which are reverted. Sections are composed
# by paramem.graph.anonymizer_prompts and parsed via the `===` sentinel
# format (paramem/graph/prompts.py::_load_prompt_sections).

=== SCAN-SYSTEM ===
You are the tagging step inside a privacy filter for a home voice assistant. Output valid JSON only.

=== SCAN ===
Do not decide what is sensitive: a later mechanical step keeps only the categories the operator configured and restores everything else verbatim. Your job is complete and accurate naming — list every value in the text below that names a specific real-world thing, and mark each one with the single keyword it is an instance of.

Keywords:
{keywords}

Rules:
- Tag only spans that occur verbatim in the text. Copy the value exactly as written, including casing.
- Pronouns (I, you, he, she, me, my, mine, ich, du, je, yo ...) and kinship or role words (my wife, your son, meine Mutter, ma femme, mi esposa, the tenant, the assessor) are NEVER values.
- A token of the form speaker0, speaker1 ... is already anonymous and is never a value.
- Common nouns are never values, even when capitalised.
- A possessive on a device name ("Oskar's Echo Dot") names the person ("Oskar") as Person and the device ("Echo Dot") as Product.

Text:
{text}

POSITIVE example:
Text: "[user] Play Queen on the Sonos office speaker. My wife Anna Schmidt called earlier from +49 152 0 445 3311."
Output: {{"mapping": {{"Queen": "Artist", "Sonos": "Product", "office": "Room", "Anna Schmidt": "Person", "+49 152 0 445 3311": "Phone"}}}}

POSITIVE example, nothing to name:
Text: "[user] Turn off the lights, please."
Output: {{"mapping": {{}}}}

POSITIVE example, a room name:
Text: "[user] Turn off the lights in the kitchen, please."
Output: {{"mapping": {{"kitchen": "Room"}}}}

Return JSON only, with exactly the key "mapping" (an object mapping each value, exactly as written, to one keyword from the list above). An empty result is {{"mapping": {{}}}}. No prose, no markdown, no extra keys.

=== ANCHOR-SYSTEM ===
You decide which of the given values, if any, the speaker introduced as their own name. Output valid JSON only.

=== ANCHOR ===
`{speaker_id}` is this session's own speaker anchor — the anonymous handle for the person speaking as `[user]` in the transcript below.

Below is a list of values that were flagged for anonymization. Decide which of these values, if any, the `[user]` introduces as THEIR OWN name — a self-introduction such as "I'm Priya", "my name is Priya", "call me Priya". Every spelling the `[user]` uses to introduce themselves folds onto the SAME anchor — if they say both "Priya" and "Priya Sharma" as self-introductions, list both. A value belonging to someone else — a friend, colleague, or anyone the `[user]` talks ABOUT rather than introduces as themselves — is NOT self-introduced, no matter what any other fact claims about them.

Values: {values}

Transcript:
{text}

POSITIVE — self-introduction in the transcript:
Values: ["Priya"]
Transcript: "[user] Hi, I'm Priya."
Output: {{"self_introduced": ["Priya"]}}

POSITIVE — NO self-introduction, the name belongs to someone else:
Values: ["Mira"]
Transcript: "[user] Mira, my friend, moved away for a new job."
Output: {{"self_introduced": []}}
Note: the `[user]` never says "I'm Mira" — Mira is the speaker's friend, not the speaker.

POSITIVE — two self-naming surface forms, both self-introduced:
Values: ["Priya Sharma", "Priya"]
Transcript: "[user] Hi, I'm Priya Sharma. [assistant] Nice to meet you. [user] You can just call me Priya."
Output: {{"self_introduced": ["Priya Sharma", "Priya"]}}

Return JSON only with exactly the key "self_introduced" (a JSON array of strings, a subset of the listed values). No prose, no markdown, no extra keys.
