# Sectioned prompt home for local anonymization. Two duties, four sections:
# SCAN marks each value in the payload that is an instance of one of the
# keywords named in `configs/schema.yaml`'s `anonymizer.scrub` and
# `anonymizer.allow` lists, rendered here as one combined keyword list —
# `sanitization.scrub` selects nothing in this file. What the operator
# scrubs leaves the text as a placeholder; what the table allows leaves
# the text verbatim; what the model marks with no keyword is restored as
# well. ANCHOR decides which marked person value the speaker introduced
# as their own name. Code — never the model — decides which keyword's
# values are kept and which are reverted. Sections are composed by
# paramem.graph.anonymizer_prompts and parsed via the `===` sentinel
# format (paramem/graph/prompts.py::_load_prompt_sections).

=== SCAN-SYSTEM ===
You mark the values in a text with keywords from a given list. Your reply is one JSON object.

=== SCAN ===
Keywords:
{keywords}

Find every span of the text below that is an instance of one of these keywords, and mark it with that keyword, spelled as in the list. Each value in the mapping is a span copied exactly as it occurs in the text, including casing. When the text holds no such span, the mapping is empty: {{"mapping": {{}}}}.

Return one JSON object with exactly the key "mapping": an object pairing each value, exactly as written, with one keyword from the list. An empty result is {{"mapping": {{}}}}.

Example:
Text:
Can you save Mira Sandberg's number, it's +46 70 555 01 23.
Output: {{"mapping": {{"Mira Sandberg": "Person", "+46 70 555 01 23": "Phone"}}}}

Example:
Text:
Jonas and I watched Interstellar and then some Adele videos on his new Samsung TV.
Output: {{"mapping": {{"Jonas": "Person", "Adele": "Artist"}}}}

Example:
Text:
call emil back and tell him the parcel is here.
Output: {{"mapping": {{"emil": "Person"}}}}

Example:
Text:
Turn the hallway light off at ten, please.
Output: {{"mapping": {{}}}}

Text:
{text}
Output:
=== ANCHOR-SYSTEM ===
You decide which of the given values, if any, the speaker introduced as their own name. Output valid JSON only.

=== ANCHOR ===
`{speaker_id}` is this session's own speaker anchor — the anonymous handle for the person speaking as `[user]` in the transcript below.

Below is a list of values that were flagged for anonymization. Decide which of these values, if any, the `[user]` introduces as THEIR OWN name — a self-introduction such as "I'm Priya", "my name is Priya", "call me Priya". Every spelling the `[user]` uses to introduce themselves folds onto the SAME anchor — if they say both "Priya" and "Priya Sharma" as self-introductions, list both. A value belonging to someone else — a friend, colleague, or anyone the `[user]` talks ABOUT rather than introduces as themselves — is NOT self-introduced, no matter what any other fact claims about them.

Values: {values}

Transcript:
{text}

POSITIVE — self-introduction in the transcript:
Values: ["Priya"]
Transcript: "[user] Hi, I'm Priya."
Output: {{"self_introduced": ["Priya"]}}

POSITIVE — NO self-introduction, the name belongs to someone else:
Values: ["Mira"]
Transcript: "[user] Mira, my friend, moved away for a new job."
Output: {{"self_introduced": []}}
Note: the `[user]` never says "I'm Mira" — Mira is the speaker's friend, not the speaker.

POSITIVE — two self-naming surface forms, both self-introduced:
Values: ["Priya Sharma", "Priya"]
Transcript: "[user] Hi, I'm Priya Sharma. [assistant] Nice to meet you. [user] You can just call me Priya."
Output: {{"self_introduced": ["Priya Sharma", "Priya"]}}

Return JSON only with exactly the key "self_introduced" (a JSON array of strings, a subset of the listed values). No prose, no markdown, no extra keys.
